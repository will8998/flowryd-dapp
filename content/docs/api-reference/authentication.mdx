# Authentication API

Authentication endpoints handle user login, registration, token refresh, and session management. All authentication uses httpOnly cookies for security.

## POST /api/auth/login

Authenticate user with Party ID and password. Sets httpOnly JWT cookies.

```typescript filename="login.ts"
// Request
fetch('/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    partyId: 'party123::participant456',
    password: 'securePassword123'
  })
});

// Response
{
  "data": {
    "user": {
      "id": "uuid-123",
      "partyId": "party123::participant456",
      "displayName": "John Doe",
      "email": "john@example.com",
      "role": "editor",
      "orgId": "org-uuid-456"
    }
  }
}

// Sets httpOnly cookies:
// - flowryd_token (JWT access token, 15min)
// - flowryd_refresh (refresh token, 7 days)
```

## POST /api/auth/register

Register new user and create organization. Returns same response as login.

```typescript filename="register.ts"
// Request
fetch('/api/auth/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    partyId: 'newparty::participant789',
    password: 'securePassword123',
    displayName: 'Jane Smith',
    email: 'jane@example.com' // optional
  })
});

// Response
{
  "data": {
    "user": {
      "id": "uuid-789",
      "partyId": "newparty::participant789",
      "displayName": "Jane Smith",
      "email": "jane@example.com",
      "role": "admin", // First user becomes admin
      "orgId": "new-org-uuid"
    }
  }
}
```

## POST /api/auth/refresh

Refresh access token using httpOnly refresh token cookie. Implements token rotation.

```typescript filename="refresh.ts"
// Request (uses httpOnly cookie automatically)
fetch('/api/auth/refresh', {
  method: 'POST'
});

// Response
{
  "data": {
    "success": true
  }
}

// Updates httpOnly cookies with new tokens
```

## POST /api/auth/logout

Clear authentication cookies and revoke refresh token family.

```typescript filename="logout.ts"
// Request
fetch('/api/auth/logout', {
  method: 'POST'
});

// Response
{
  "data": {
    "success": true
  }
}

// Clears all auth cookies and revokes tokens
```

## GET /api/auth/me

Get current authenticated user information from JWT cookie.

```typescript filename="me.ts"
// Request
fetch('/api/auth/me');

// Response
{
  "data": {
    "user": {
      "id": "uuid-123",
      "partyId": "party123::participant456",
      "displayName": "John Doe",
      "email": "john@example.com",
      "role": "editor",
      "orgId": "org-uuid-456"
    }
  }
}
```
