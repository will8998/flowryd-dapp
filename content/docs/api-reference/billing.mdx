# Billing API

Billing endpoints manage subscription plans, subscriptions, invoices, and payment methods. All endpoints require admin role.

## GET /api/admin/plans

List all subscription plans.

```typescript filename="list-plans.ts"
// Request
fetch('/api/admin/plans');

// Response
{
  "data": [
    {
      "id": "plan-uuid-123",
      "name": "Professional",
      "tier": "pro",
      "priceAmount": 99900, // cents
      "priceCurrency": "USD",
      "interval": "monthly",
      "features": [
        "unlimited-flows",
        "advanced-analytics",
        "priority-support"
      ],
      "isActive": true,
      "createdAt": "2024-01-01T00:00:00Z"
    },
    {
      "id": "plan-uuid-456",
      "name": "Enterprise",
      "tier": "enterprise",
      "priceAmount": 299900,
      "priceCurrency": "USD",
      "interval": "monthly",
      "features": [
        "unlimited-everything",
        "custom-integrations",
        "dedicated-support"
      ],
      "isActive": true
    }
  ]
}
```

## POST /api/admin/plans

Create new subscription plan.

```typescript filename="create-plan.ts"
// Request
fetch('/api/admin/plans', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: 'Starter',
    tier: 'basic',
    priceAmount: 2900, // $29.00
    priceCurrency: 'USD',
    interval: 'monthly',
    features: [
      'up-to-5-flows',
      'basic-analytics',
      'email-support'
    ]
  })
});

// Response
{
  "data": {
    "plan": {
      "id": "new-plan-uuid",
      "name": "Starter",
      "tier": "basic",
      "priceAmount": 2900,
      "priceCurrency": "USD",
      "interval": "monthly",
      "features": ["up-to-5-flows", "basic-analytics", "email-support"],
      "isActive": true,
      "createdAt": "2024-01-25T18:30:00Z"
    }
  }
}
```

```typescript filename="list-subscriptions.ts"
// Response

      "cancelAtPeriodEnd": false,
      "createdAt": "2024-01-01T00:00:00Z"

```

## POST /api/admin/subscriptions

Create new subscription for organization.

```typescript filename="create-subscription.ts"
// Request
fetch('/api/admin/subscriptions', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    orgId: 'org-uuid-789',
    planId: 'plan-uuid-123'
  })
});

// Response
{
  "data": {
    "subscription": {
      "id": "new-sub-uuid",
      "orgId": "org-uuid-789",
      "planId": "plan-uuid-123",
      "status": "active",
      "currentPeriodStart": "2024-01-25T18:45:00Z",
      "currentPeriodEnd": "2024-02-25T18:45:00Z",
      "createdAt": "2024-01-25T18:45:00Z"
    }
  }
}
```

## PATCH /api/admin/subscriptions/[subId]

Update subscription status.

```typescript filename="update-subscription.ts"
// Request
fetch('/api/admin/subscriptions/sub-uuid-123', {
  method: 'PATCH',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    status: 'canceled',
    cancelAtPeriodEnd: true
  })
});

// Response
{
  "data": {
    "subscription": {
      "id": "sub-uuid-123",
      "status": "canceled",
      "cancelAtPeriodEnd": true,
      "canceledAt": "2024-01-25T19:00:00Z",
      "updatedAt": "2024-01-25T19:00:00Z"
    }
  }
}
```
